# Verbum-Catala-Legal

Política de Privacitat — Verbum-Català

Última actualització: Maig 2026

Verbum-Català respecta la privacitat dels usuaris.

Dades recollides

Aquesta aplicació no recull dades personals identificables.

No es demana:

nom
correu electrònic
ubicació
número de telèfon
Emmagatzematge local

L'aplicació desa algunes dades localment al dispositiu per millorar l'experiència d'ús, com ara:

progrés de l'usuari
configuració
dificultat seleccionada
historial d'exàmens
diplomes desbloquejats

Aquestes dades no s'envien a cap servidor extern.

Connexió a Internet

Verbum-Català pot funcionar sense connexió a Internet.

Publicitat

Actualment l'aplicació no mostra anuncis.

Compartició de dades

No es comparteixen dades amb tercers.
